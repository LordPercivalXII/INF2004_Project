## Motion Classification System

### 6 Motion States Implemented

| State | Condition | Threshold | Use Case |
|-------|-----------|-----------|----------|
| **STATIONARY** | Low motion | \|a\|<0.5g, \|gz\|<10° | Robot at rest |
| **ACCELERATING** | Linear acceleration | \|a\|>1.5g | Flat terrain motion |
| **TURNING** | Rotational motion | \|gz\|>20°/s | Steering maneuvers |
| **CLIMBING** | Upward acceleration | az>1.3g | Ascending hump/slope |
| **DESCENDING** | Downward acceleration | az<0.7g | Descending hump/slope |
| **IMPACT** | Shock/collision | \|a\|>3.0g | Collision detection |

### Tilt Angle Detection

Roll (φ) and Pitch (θ) computed from gravity vector:
- **Roll** = atan2(ay, az) → Left/right tilt
- **Pitch** = atan2(-ax, √(ay²+az²)) → Forward/backward tilt
- **Accuracy**: ±2° (within sensor calibration)
- **Range**: Valid for ±60° from horizontal

## Event Data Stream

Every 10ms (100Hz), the IMU task posts a SystemEvent containing:

```c
{
    .type = SYSTEM_EVENT_IMU
    .timestamp_ms = (current time in ms)
    .data.imu = {
        .acceleration_x_g,              // ±4g in g units
        .acceleration_y_g,              // ±4g in g units
        .acceleration_z_g,              // ±4g in g units
        .turn_rate_dps,                 // ±1000°/s in degrees/sec
        .estimated_hump_height_m,       // Meters via h=v²/2g
        .shock_detected,                // Boolean: |a| > 3.0g?
        .sensor_valid,                  // Boolean: sensor working?
        .motion_state,                  // NEW: STATIONARY/ACCELERATING/TURNING/CLIMBING/DESCENDING/IMPACT
        .tilt_roll_deg,                 // NEW: Roll angle in degrees
        .tilt_pitch_deg                 // NEW: Pitch angle in degrees
    }
}
```

Vehicle Controller can subscribe and react to this full motion context.
