  Trigger: Periodic FreeRTOS task

NFR9: Obstacle Halt Latency
  Specification: ≤100ms from detection to halt command
  Constraint: Coordinate with Buddy 4 (IMU) shock detection
  Both should trigger motor halt with priorities TBD

HARDWARE CONFIGURATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Sensor: HC-SR04 Ultrasonic Distance Sensor
  - TRIG pin: GP3 (output, pulse trigger)
  - ECHO pin: GP7 (input, pulse response)
  - VCC: 5V
  - GND: GND
  - Operation: Send 10µs pulse → measure echo width → calculate distance

Signal Processing:
  - Pulse frequency: 40kHz (ultrasonic, inaudible)
  - Echo pulse width: 150µs to 25ms (proportional to distance)
  - Distance = (echo_time_us * 343) / 20000 (speed of sound)
  - Require burst reads/GPIO edge detection

Electrical Interface:
  - TRIG: Simple GPIO digital output (push-pull)
  - ECHO: GPIO edge detection (rising → falling to measure pulse width)
  - Consider: RP2040 can measure pulse width via PWM input or by polling GPIO
